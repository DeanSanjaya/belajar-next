# LearnNext - Next.js Learning Portal 🚀

Selamat datang di projek belajar Next.js kamu! Projek ini telah diubah dari boilerplate standar menjadi sebuah **Portal Pembelajaran Interaktif**.

## 🛠️ Apa yang ada di sini?

1.  **Dashboard Utama**: Navigasi ke berbagai modul pembelajaran.
2.  **Modul Routing**: Pelajari cara kerja sistem routing berbasis file di Next.js.
3.  **Interactive Explorer**: Coba langsung simulasi struktur folder vs URL.
4.  **UI Premium**: Menggunakan Tailwind CSS v4, Framer Motion, dan Lucide Icons untuk pengalaman yang menyenangkan.

## 📚 Cara Menggunakan

1.  **Jalankan Projek**: Pastikan terminal kamu sedang menjalankan `npm run dev`.
2.  **Buka di Browser**: Kunjungi [http://localhost:3000](http://localhost:3000).
3.  **Mulai Belajar**: Klik pada modul "Routing Fundamentals" untuk memulai pelajaran pertama.
4.  **Eksperimen**: Ikuti bagian "Tantangan Untukmu" di setiap pelajaran untuk mencoba langsung di kode ini.

## 🏗️ Struktur Projek

- `app/`: Berisi semua halaman dan modul (Routing, Components, dll).
- `components/`: UI komponen yang bisa kamu pelajari dan gunakan kembali.
- `globals.css`: Konfigurasi tema dan desain tokens.
